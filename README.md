## Sobre mí

Soy desarrollador backend en formación, enfocado en construir servicios mantenibles, automatizaciones y soluciones preparadas para ejecutarse en la nube.

Aprendo construyendo proyectos reales, documentando las decisiones técnicas y mejorando progresivamente la calidad del código.

Actualmente trabajo en tres áreas principales:

- **Backend:** APIs REST con Node.js, Express, Flask y Spring Boot.
- **Cloud & DevOps:** AWS, Docker, GitHub Actions y automatización de despliegues.
- **Data & Automation:** procesamiento de datos con Python, pandas y servicios de almacenamiento cloud.

Mi objetivo es crecer hacia un perfil de **Cloud Engineer / AI Engineer**, combinando desarrollo backend, arquitectura cloud, datos e inteligencia artificial.

## Proyectos destacados

### Data Pipeline con AWS

<a href="https://github.com/ldordellygithub/data-pipelinetee">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=ldordellygithub&repo=data-pipelinetee&theme=transparent&hide_border=true" alt="data-pipelinetee">
</a>

Pipeline de datos automatizado que procesa un archivo CSV, filtra la información con `pandas` y sube el resultado a Amazon S3 mediante `boto3`.

**Tecnologías:** Python · pandas · boto3 · Docker · GitHub Actions · AWS S3

**Incluye:**

- Ejecución automática mediante GitHub Actions
- Configuración mediante variables de entorno
- Manejo de errores con códigos de salida
- Almacenamiento de logs y artefactos
- Contenedor Docker reproducible
